# containers

This repository holds the OCI container configuration files I use. Basically, these files are `Dockerfile`s and `docker-compose.yml`s, since Docker is the container engine the industry has widely adopted.

I personally use [Podman](https://podman.io/) as the OCI container engine, and the configurations in this repository are tested under Podman. Please feel free to [open an issue](https://github.com/cylixlee/containers/issues/new) or PR.
